# ปรับ UI ทั้งระบบให้เป็น YouTube Dark อย่างสม่ำเสมอ

## เป้าหมาย
- คงตำแหน่ง ขนาดพื้นที่ และขั้นตอนใช้งานเดิมทั้งหมด
- เปลี่ยนเฉพาะภาษาภาพของ UI ให้ใกล้ YouTube Dark: พื้นดำ/เทากลาง ผิวทึบ ขอบบาง ปุ่มชัด และไม่ใช้สีแดงหรือน้ำเงินเป็นสีประจำหน้าจอ
- แก้อาการปุ่มผิดรูป สถานะไม่ชัด เมนูซ้อน และส่วนที่ยังหลงเหลือสไตล์กระจกเดิม

## งานที่จะทำ

### 1. ทำระบบสีให้เป็นกลางจริงทุกสถานะ
- รวมค่าสีของธีมปกติและธีมมืดให้ใช้ดำ เทา และขาวชุดเดียวกัน เพื่อไม่ให้โทนน้ำเงินกลับมาเมื่อมีคลาสธีมมืด
- เปลี่ยนพื้นผิวสีน้ำเงินเข้มที่เขียนแยกไว้ในเมนู หน้าต่าง ป้ายคำอธิบาย และแถบเอกสาร เป็นสีจากระบบกลาง
- เอาแสงฟุ้ง เงาขาว และพื้นโปร่งแบบกระจกออกจากส่วนควบคุมหลัก
- สีของเนื้อเพลงและชุดสีสำหรับงานส่งออกยังคงเลือกได้ เพราะเป็นข้อมูลผลงาน ไม่ใช่สีของหน้าจอ

### 2. ปรับชุดปุ่มตามแนวทาง YouTube
- ทำปุ่มข้อความ ปุ่มไอคอน ปุ่มหลัก ปุ่มรอง และปุ่มเลือกสถานะให้มีความสูง ระยะ ไอคอน และมุมโค้งสม่ำเสมอ
- ใช้พื้นเทาทึบเมื่อชี้ เมื่อตั้งค่าอยู่ และเมื่อกด แทนการย่อ/ขยายหรือเรืองแสงมากเกินไป
- ทำสถานะปิดใช้งาน โฟกัส รายการโปรด เล่นเพลง โหมดแปล และแท็บที่เลือกให้มองออกโดยไม่พึ่งสีแดงหรือน้ำเงิน
- ปรับปุ่มควบคุมหน้าต่างให้ไม่ดูเหมือนปุ่มที่กดได้บนเว็บเมื่อไม่มีฟังก์ชันเดสก์ท็อป

### 3. เก็บส่วนประกอบที่ยังเป็นดีไซน์เก่า
- แถบบนและตัวเลือก ปกติ/เฟด/เอกสาร
- การ์ดปกเพลง แถบควบคุมเพลง และเมนูสามจุด
- พื้นที่เนื้อเพลง ช่องแก้ไข ปุ่มค้นหา และสถานะหน้าว่าง
- แถบเอกสาร เมนูย่อย รายการ และสถานะที่เลือก
- หน้าต่างค้นหา นำเข้า ส่งออก ตั้งค่า คีย์ลัด คลังเพลง และตั้งค่าเนื้อเพลงเดสก์ท็อป
- กล่องเลือก แถบเลื่อน ป้ายคำอธิบาย กล่องยืนยัน และข้อความแจ้งเตือน

### 4. แก้อาการใช้งานที่พบระหว่างตรวจ
- ตรวจลำดับชั้นของเมนูและหน้าต่างไม่ให้ถูกตัดหรือซ้อนผิด
- ตรวจพื้นที่คลิก ปุ่มที่ไม่มีผลบนเว็บ การปิดด้วย Escape/คลิกด้านนอก และสถานะ disabled
- ตรวจข้อความและไอคอนไม่ล้นหรือเบียดกันที่หน้าจอปัจจุบัน
- รักษาความสามารถค้นหา เล่น แก้เนื้อเพลง นำเข้า ส่งออก ตั้งค่า และคีย์ลัดเหมือนเดิม

### 5. ตรวจรับงาน
- เปิดและทดลองทุกเมนู/หน้าต่างที่เข้าถึงได้จากหน้าหลัก
- ทดสอบปุ่มหลัก โหมดแสดงผล เมนูสามจุด แถบเอกสาร ช่องกรอก กล่องเลือก และแถบเลื่อน
- ตรวจซอร์สซ้ำว่าไม่มีสีฟ้า/น้ำเงินในส่วนตกแต่ง UI และไม่มีสไตล์ Apple glass หลงเหลือในส่วนที่แสดงผล
- ตรวจหน้าจอเดสก์ท็อปและพื้นที่แคบ พร้อมยืนยันว่าไม่มีข้อผิดพลาดบนหน้าจอ

## รายละเอียดทางเทคนิค
- ใช้สีและสถานะจาก design tokens กลางแทนค่าสีที่เขียนกระจายตามแต่ละไฟล์
- ปรับชุด UI ที่ใช้ร่วมกันก่อน แล้วเก็บส่วนที่ยังเขียนปุ่มหรือหน้าต่างเฉพาะจุด
- ลด motion เหลือเฉพาะการเปิดเมนู/หน้าต่างและการตอบสนองสั้น ๆ โดยรองรับ reduced motion
