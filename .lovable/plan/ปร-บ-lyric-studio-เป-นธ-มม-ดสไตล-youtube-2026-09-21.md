# ปรับ Lyric Studio เป็นธีมมืดสไตล์ YouTube

## เป้าหมาย
นำแอปจาก `src.zip` มาแสดงเป็นหน้าหลัก โดยคงตำแหน่งและการทำงานเดิม แล้วเปลี่ยนภาพลักษณ์จากกระจกโปร่งแบบ Apple เป็น UI มืด เรียบ และคมแบบ YouTube โดยไม่ใช้สีแดง

## สิ่งที่จะทำ
- ย้ายเฉพาะซอร์สและทรัพยากรที่จำเป็นจากไฟล์ ZIP เข้าสู่โปรเจกต์ โดยไม่รวมไฟล์ build, workflow หรือข้อมูล Git
- ปรับแอปให้ทำงานบนโครงสร้างโปรเจกต์ปัจจุบัน โดยหน้า `/` เปิด Lyric Studio โดยตรง
- คงโครงหน้าหลักเดิม: แถบด้านข้าง พื้นที่เครื่องเล่น พื้นที่เนื้อเพลง แถบควบคุมด้านล่าง และหน้าต่างตั้งค่าต่าง ๆ
- เปลี่ยนชุดสีเป็นพื้นดำ/เทาเข้มแบบ YouTube เช่น พื้นหลักดำเกือบสนิท แผงสีถ่าน เส้นแบ่งเทา และข้อความขาว/เทา
- ใช้สีเน้นแบบเป็นกลางแทนแดง เช่น ขาวสว่างและเทาอ่อน สำหรับสถานะเลือก ปุ่มหลัก แถบเวลา และจุดโฟกัส
- ลดความโปร่ง เบลอ เงาหนัก และเอฟเฟกต์กระจก ให้เป็นพื้นผิวทึบเรียบ พร้อมสถานะชี้/กดแบบ YouTube
- ใช้ Sora สำหรับหัวข้อ และ Manrope สำหรับข้อความทั่วไป โดยรักษาการอ่านภาษาไทยให้ชัดเจน
- ปรับปุ่ม ช่องกรอก เมนู ตัวเลือก สไลเดอร์ หน้าต่างป๊อปอัป และแถบเลื่อนให้ใช้ภาษาภาพเดียวกันทั้งแอป
- รักษาพฤติกรรมเดิมของการค้นหา เล่นเพลง แก้เนื้อเพลง นำเข้า ส่งออก ตั้งค่า และคีย์ลัดเท่าที่รองรับในเว็บ
- เพิ่มชื่อและคำอธิบายหน้าให้ตรงกับ Lyric Studio

## การตรวจสอบ
- ตรวจหน้าหลักในขนาดเดสก์ท็อปว่าพื้นที่ทั้งหมดไม่ทับกันและข้อความไม่ล้น
- ทดลองส่วนควบคุมหลักและหน้าต่างป๊อปอัปที่เปิดได้
- ตรวจว่าไม่มีสีแดงหลงเหลือในสถานะหลัก และโทนภาพรวมยังใกล้ YouTube Dark
- ตรวจข้อผิดพลาดระหว่างโหลดและการใช้งานก่อนส่งมอบ

## หมายเหตุทางเทคนิค
ตัว ZIP เป็นแอป React/Electron เดิม ส่วนโปรเจกต์ปลายทางเป็นเว็บแอป จึงจะนำหน้าจอและตรรกะที่ใช้ในเว็บมาใช้ตรง ๆ และปรับส่วนเฉพาะเดสก์ท็อปให้มีทางเลือกที่ใช้งานได้บนเว็บ โดยไม่เพิ่มระบบหลังบ้านใหม่
